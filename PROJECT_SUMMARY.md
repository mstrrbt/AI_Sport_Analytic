# Краткое описание CoachMind Football

CoachMind Football — это MVP ИИ-системы для помощи футбольному тренеру.

Главная идея: тренеру нужно быстро понять, кто из игроков сейчас в лучшей форме, кого лучше поставить в стартовый состав и какие замены могут усилить команду.

## Что делает система

Система показывает:

- форму игроков;
- топ игроков команды;
- рекомендуемый состав 4-3-3;
- what-if замену игрока;
- отдельный модуль физической нагрузки.

## Какие данные используются

Для формы и состава используется StatsBomb Open Data по UEFA Euro 2024.

Для физической нагрузки используется SkillCorner Open Data по AUS A-League 2024/2025.

## Основная модель

Используется CatBoostRegressor.

Модель предсказывает form_score — оценку формы игрока от 0 до 100.

## Что уже реализовано

1. Загрузка и обработка данных.
2. Создание признаков игрока.
3. Расчёт form_score.
4. Обучение CatBoost.
5. Подбор состава.
6. What-if замены.
7. Модуль нагрузки.
8. Веб-приложение в браузере.

## Главное ограничение

Это MVP. Он показывает рабочую идею продукта, но не заменяет тренера, врача или профессионального аналитика.
