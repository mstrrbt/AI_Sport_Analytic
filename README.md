# CoachMind Football

CoachMind Football — MVP ИИ-системы для футбольного тренера.

Проект помогает:
- оценивать форму игроков;
- выбирать стартовый состав;
- проверять what-if замены;
- смотреть физическую нагрузку игроков.

## Данные

В проекте используются два открытых источника:

1. StatsBomb Open Data:
- UEFA Euro 2024;
- 51 матч;
- события матча;
- удары, голы, xG, передачи, прессинг и другие действия.

2. SkillCorner Open Data:
- AUS A-League 2024/2025;
- физическая нагрузка;
- дистанция, спринты, ускорения, максимальная скорость.

Важно: StatsBomb и SkillCorner используются как отдельные демо-модули.

## Модули проекта

1. Player Form Model  
Оценивает форму игрока по событиям матча.

2. Lineup Optimizer  
Подбирает стартовый состав под схему 4-3-3.

3. What-if Substitution  
Показывает, что изменится при замене одного игрока другим.

4. Load Agent  
Показывает физическую нагрузку игроков по SkillCorner.

5. Streamlit App  
Открывает MVP в браузере.

## Как запустить

Перейти в папку проекта:

cd ~/Desktop/coachmind_football

Активировать окружение:

source .venv/bin/activate

Запустить приложение:

streamlit run app/coachmind_app.py

Или одной командой:

./run_mvp.sh

После запуска открыть:

http://localhost:8501

## Ограничения MVP

- form_score создан как внутренняя метрика проекта;
- модуль нагрузки не является медицинским прогнозом;
- система не заменяет тренера или врача;
- рекомендации являются аналитической подсказкой.
